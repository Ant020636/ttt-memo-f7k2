รายชื่อพนักงานดึงมาจากไฟล์ Sales Employee and Buyer Master Data.xlsx ( คน) จำรหัสไม่ได้ก็พิมพ์ชื่อได้เลย ระบบจะเติมรหัสให้เอง

รหัสพนักงานคือหัวใจของระบบเลขที่เอกสาร — เลขจะออกเป็น MEMO-{รหัสพนักงาน}-{ปี ค.ศ.}-{เดือน}-{วัน}-{ลำดับ} เช่น MEMO-S-SE001-2026-08-10-01
ลำดับ 2 หลักท้ายคือ "เอกสารฉบับที่เท่าไรของวันนั้น" — ถ้าไม่ใส่ Sale ที่ออก MEMO 2 ฉบับในวันเดียวกันจะได้เลขซ้ำกัน ทำให้แยกเอกสารไม่ออก จึงต้องมีไว้ (ถ้าไม่ต้องการจริงๆ แก้ CFG.showSeq = false ในไฟล์ได้)

📚 ทะเบียน MEMO ที่ออกจากเครื่องนี้

นี่คือ สำเนาสำรองในเครื่อง เท่านั้น (เก็บใน localStorage ของเบราว์เซอร์ — ล้างประวัติเบราว์เซอร์แล้วหาย) ทะเบียนตัวจริงต้องอยู่ในไฟล์ Excel บน SharePoint ดูวิธีที่ปุ่ม "วิธีใช้"

❓ วิธีใช้

1) ตั้งค่าครั้งแรก — กด ⚙️ ตั้งค่าผู้ใช้ ใส่รหัสพนักงาน/ชื่อ/ตำแหน่ง แล้วบันทึก

2) กรอกเอกสาร — พิมพ์ทับบนฟอร์มได้เลย ช่องที่ปล่อยว่างจะพิมพ์ออกมาเป็นเส้นจุดให้เขียนมือ (บล็อกเอกสารแนบ ถ้าเว้นว่างทั้งหมดจะถูกซ่อนตอนพิมพ์)
ช่อง ผู้จัดทำ / ผู้ตรวจสอบ / ผู้อนุมัติ พิมพ์ชื่อแล้วเลือกจากรายการ ระบบจะเติมตำแหน่งให้เอง

3) พิมพ์เป็น PDF — กด 🖨️ แล้วในหน้าต่างพิมพ์ตั้งค่า: ปลายทาง = Save as PDF · Margins = Default · เอาเครื่องหมายถูก Headers and footers ออก
ช่อง File name จะขึ้นชื่อไฟล์ให้อัตโนมัติแล้ว กด Save ได้เลย

4) เก็บไฟล์ — บันทึกลงโฟลเดอร์ SharePoint ตามปีและเดือน แล้วกด 📋 คัดลอกบรรทัดทะเบียน ไปวางต่อท้ายไฟล์ Excel ทะเบียน MEMO.xlsx

5) แก้เอกสารเก่า — กด 💾 บันทึกร่าง เก็บไฟล์ .json ไว้ข้างๆ PDF จะเปิดมาแก้แล้วพิมพ์ใหม่ได้ โดยเลขที่เอกสารไม่เปลี่ยน
📱 กำลังใช้บนมือถือ — เลขที่เอกสารจะลงท้ายด้วย -M เพื่อไม่ให้ชนกับเลขที่ออกจากคอม iPhone: กดพิมพ์ → Share → Print → ถ่างนิ้วบนภาพตัวอย่าง → Share → Save to Files
Android: กดพิมพ์ → เลือกปลายทาง "Save as PDF" → บันทึก
